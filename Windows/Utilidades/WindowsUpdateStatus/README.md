# Get-WindowsUpdateStatus

Muestra las últimas entradas del historial de Windows Update. Si el módulo PSWindowsUpdate está instalado, también lista las actualizaciones pendientes.

Solo lectura. No busca, descarga ni instala actualizaciones.

## Uso

```powershell
.\Get-WindowsUpdateStatus.ps1
```

Requiere PowerShell 5.1 o superior. Para ver las pendientes, instala antes el módulo con `Install-Module PSWindowsUpdate` (lo haces tú, el script no lo instala).
