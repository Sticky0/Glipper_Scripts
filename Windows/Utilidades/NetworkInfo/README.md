# Get-NetworkInfo

Muestra los adaptadores de red activos con su IPv4, puerta de enlace y servidores DNS.

Solo lee información. No cambia la configuración de red.

## Uso

```powershell
.\Get-NetworkInfo.ps1
```

Requiere PowerShell 5.1 o superior y el módulo NetTCPIP (incluido en Windows 8 y posteriores).
